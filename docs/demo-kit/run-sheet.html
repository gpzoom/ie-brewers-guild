Inland Scan Pass — demo run sheet

About 5 minutes. Runs on the staging site with the four draft Sample members (the public never sees them). Staff code for every demo plate: 2468.

Before you go

  • Guild → Scan Pass → Passes: Testing: offers work now is on (until we merge to main).
  • Same page: press Reset demo visits — clears today's visits so every reward works again.
  • Demo phone: Alex (Beer Trail Pass) open from the Home Screen icon. Second browser or phone: Jordan (free pass).
  • One 4×6 stand card per business (plate + staff QR), spaced out like four businesses.

 

  • Laptop signed in as Guild admin, on Sample Brewery #1 → Edit as them → Scan Pass.
  • Phones charged; Wi-Fi or a hotspot that works at the venue.
  • The explainer video ready to play (optional opener).
  • Leave-behinds, and a pen for your contact line.

If something goes wrong

  • "This taproom isn't taking Scan Pass check-ins right now" — you're on the live site. Use the printed demo plates (they point at staging).
  • No staff QR handy — tap Enter the staff code instead, type 2468.
  • "Checked in today" or the nickel offer is gone — press Reset demo visits (Guild → Scan Pass → Passes), then scan again.

 

  • No Beer Trail offer for Alex — the testing switch is off, or Alex's pass didn't record.
  • Asked to sign in — enter Alex's email, tap Email me a code, read the code from your inbox.
  • After the demo — press Reset demo visits. Before real commission reports: node scripts/demo-kit.mjs teardown --yes --passes.

Never let a guest type their own email: sign-ins send real emails, and staging shares the live database. Use your own +demo addresses.
