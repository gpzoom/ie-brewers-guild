# Brief — "Sending email from your guild address"

- **Who it's for:** Guild officers (president@, info@ and future role addresses) who set up Gmail
  "Send mail as" themselves in the guild Gmail account. Companion to the written officer guide:
  https://claude.ai/artifact/96tzLovbHmvaW2PCAAUzcd
- **What it teaches:** the one-time setup (settings → Accounts and Import → Send mail as →
  name and address → SMTP smtp.resend.com, port 465, username `resend`, the sending password, SSL →
  confirmation link → "Reply from the same address") and a test send, then the ground rules.
- **Look and voice:** same as `../google-food-calendar/` (frame.md, fonts, "My Voice v3" on ElevenLabs,
  captions from the narration). About 3 minutes, 1920×1080.
- **Gmail screens** are simplified sketches labeled "simplified", never copies of Google's UI.
  Labels are Gmail's real wording. The sending password is always shown as dots: no real key ever appears.
- **Sample addresses:** president@iscbrewersguild.org, sender name "ISC Brewers Guild President".
  The Gmail account is shown as "Guild Gmail", never a real Gmail address.
- Left out to keep it short (in the written guide): the phone app and the signature.
